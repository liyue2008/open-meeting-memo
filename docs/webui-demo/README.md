# 本地 WebUI · 可点击设计预览

> 历史设计归档（2026-10-17）：本目录保留桌面实现前的离线静态原型和研究，不是当前产品规范。当前 Tauri 桌面实现、Mantine 界面和验收边界以 [桌面开发](../desktop.md)、[冻结契约](../../contracts/desktop/v1/README.md)及[桌面验收](../desktop-acceptance.md)为准；下文“待实现／待确认”描述当时状态，不代表当前能力或新的开发承诺。

**这是一套离线静态原型，用来确认页面、功能和交互；没有开发后端，也没有接入真实 OMM。**

## 打开方式

1. 在 Finder 中进入 `docs/webui-demo/`，双击 [`index.html`](index.html)，使用现代浏览器打开。
2. 保持本目录的 HTML、CSS、JS 文件相邻（包括 `theme.js` 和 `palette.css`）。不需要启动服务、构建或安装依赖。
3. 左下角「恢复演示数据」恢复初始六场虚构会议。窄屏可在「使用帮助」中恢复；顶端导航可横向滚动。

入口：[会议库](index.html#library) · [会议工作区](index.html#meeting/paper) · [处理队列](index.html#queue) · [设置](index.html#settings) · [状态与诊断](index.html#diagnostics) · [使用帮助](index.html#help)。

浏览器对 `file://` 本地存储的支持不同。读取、解析或写入失败时，页面显示提示并降级为内存演示；不会因此访问真实文件。关闭后可能丢失演示修改。

## 设计取向

- **会议资料是主角**：左侧固定导航，会议库以列表查找，工作区以文档阅读为中心。没有收入、活跃度等无关统计仪表盘。
- **Logo保持简约，字母分两色**：圆角底形、品牌底色、全称及位置不变；保留自行绘制的内联SVG字形，`o` 右上角轻微斜切、两个 `m` 一致圆弧和圆端竖笔，字间保留间隔。只让 `o` 用蓝墨色：浅色外观为近黑 `#000304`，深色外观为藏蓝 `#213b78`；两个 `m` 保留原白色 `#ffffff` / 墨绿 `#27302d`。每种外观均只有两种字色，靠首字母变化增加识别度；全部字母对品牌底色至少4.5:1，实际小尺寸仍清楚，不用渐变、动画或整体透明度。只在Logo选择器内着色，不改全局颜色；不加装饰、不下载字体，固定比例居中缩放，沿项目Apache-2.0许可。项目文档另用同字形、同套明暗配色的[独立SVG](../assets/omm-logo.svg)，自带不透明圆角底色，在浅深文档背景均可辨认，按浏览器的系统明暗偏好切换，无脚本或外部资源；未实测GitHub线上渲染。两者均仅是静态标志，不涉及原生App图标打包。
- **统一而克制**：Radix Colors 的冷灰 Slate 底色、Teal 青绿操作和有语义的状态色；浅深两套完整层级，系统中文字体，无图片、字体下载或第三方组件运行时。
- **用户能理解的处理状态**：显示会议标题、阶段、完成段数和恢复入口，不展示大串内部任务编号。部分逐字稿、无有效音频、旧结果与新尝试分别解释。
- **危险操作先说明影响**：删除、取消、停止封存、重新处理、重置均先确认；已有产物不因失败或取消消失。
- **原型不代替权限与认证检查**：真实服务未连接，模型、认证、权限未检测，通知可见性未知。虚构会议的「已完成」只表示演示结果。

## 明暗外观与开源配色

- 页面右上角「外观」明确提供 **跟随系统 / 浅色 / 深色**，窄屏也保留。默认跟随系统，系统外观改变会实时同步；手动选浅色或深色后不受系统改变覆盖，切回系统立即同步。无需修改 OS 来体验，可直接手动切换。
- 只存非敏感外观键 `omm-webui-theme-v1`，刷新保留偏好。存储损坏时回到跟随系统并提示，重新选择即可修复；读写被拒绝时本次仍可切换，刷新后可能恢复此前保存的外观或跟随系统。外观与虚构会议数据独立；「恢复演示数据」不覆盖外观选择。
- `theme.js` 在样式加载前同步应用外观，`color-scheme` 与有效主题一致，原生表单随之变化。主题切换只改根节点属性，不重建页面、不丢设置草稿/当前会议/筛选/无声播放位置。CSS 尊重 `prefers-reduced-motion`，不做主题过渡动画。
- 采用 [Radix Colors 官方设计系统](https://www.radix-ui.com/colors/docs/overview/usage)的 Slate/Teal 及 Red/Amber/Blue/Green 不透明色阶；按[官方色阶用途](https://www.radix-ui.com/colors/docs/palette-composition/understanding-the-scale)分别映射底色、悬停、控件、状态和文字，不简单反转背景。主按钮为保证小字对比，明亮模式仍用 Teal 11 + 白字；暗色使用下述定制鲜明青绿 + 深字。
- 来源固定为 [`@radix-ui/colors` 3.0.0，commit `dbdb85470547c7d34b9001f48fddb08ded335979`](https://github.com/radix-ui/colors/tree/dbdb85470547c7d34b9001f48fddb08ded335979)，只从该版 `src/light.ts` / `src/dark.ts` 提取本地色值到 `palette.css`，没有安装或执行上游代码。[MIT 许可原文](RADIX-COLORS-LICENSE.txt)含 Modulz/WorkOS 版权，随本演示保留；不改变项目许可。
- 深色采用「柔和阅读底色 + 鲜明小面积点缀」：`styles.css` 仅在深色作用域覆盖部分色值，背景 `#252a2f`、面板 `#2b3035`、正文/标题 `#c9cfd3`、次要文字 `#a7b0b7` 保持柔和；青绿链接/选中态文字 `#48d4b6`、主按钮/播放按钮/波形 `#27c2a4`、按钮悬停 `#3bd0b2` 提高饱和度，进度条同步强调色。只增强小面积点缀，不改变状态色、装饰边线、焦点色或无卡片阴影的阅读层次。以上覆盖是本演示的自定义色值，不是 Radix 原始 palette；`palette.css` 的144个上游色值与许可原样保留。浅色颜色与布局不变，不增加主题选项，不用整体透明度或亮度滤镜。测试保留小字4.5:1、关键控件/焦点3:1门槛，并限制深色正文对比不超过10:1；实际舒适度仍由用户确认。
- 选型依据：WorkOS 维护，官方提供成套明暗及无障碍色阶；2026-10-17读取[公开仓库](https://github.com/radix-ui/colors)元数据为1699 stars，仅作为社区使用迹象，不据此声称行业标准或所有组合自动达标。也简比过 [Catppuccin](https://github.com/catppuccin/catppuccin)（MIT、四种风味），本界面优先 Radix 的阅读/表单/状态语义阶。

## 侧栏图标与收缩

- 左侧「收起侧栏」按钮可切换图标栏；收起后同一位置的按钮用于展开。桌面默认展开；窄屏保持顶部导航，不变成覆盖正文的抽屉，两种模式均可切换。收起后保留会议/处理计数、未连接状态及恢复演示入口；鼠标悬停或键盘聚焦显示文字提示，Escape关闭提示。当前页同时用位置标记、字重及 `aria-current` 表达，切换按钮同步 `aria-expanded`。
- 图标在 `index.html` 内**自行绘制**，没有复制或执行第三方图标包：打开的书表示会议库、清单表示处理队列、齿轮表示设置、脉冲面板表示状态诊断、问号圆表示帮助、分栏箭头表示收缩/展开、减号圆表示未连接、回转箭头表示恢复。全部为24×24视框、1.8线宽、圆端线性SVG，20px显示；使用 `currentColor` 随明暗和状态变化，不依赖Unicode/字体字形。与本仓库代码同适用Apache-2.0许可，不新增第三方版权notice；Radix配色许可仍原样保留。测试记录实际图形包围盒和描边长度，并配合截图检查视觉重量。
- 只保存非敏感布局键 `omm-webui-sidebar-v1`（`expanded` / `collapsed`），与主题、业务数据独立。坏值或读取拒绝时默认展开并提示；写入拒绝仍可当次切换，刷新可能恢复此前保存的布局或默认展开，不清除旧偏好。「恢复演示数据」不重置主题或侧栏偏好。侧栏切换只改根属性及导航控件，不重新生成业务内容，不丢筛选、配置/弹窗草稿或模拟播放位置；主题切换不改变侧栏布局。

### 推荐走查路径

1. 先切换今日/本周/最近3天/最近7天，试手动更早日期与清除筛选；再搜索「纸舟」→ 打开体验评审 → 先体验顶部无声播放器，再阅读纪要与只读行动项 → 点击 `00:46` → 搜索逐字稿 → 拖动无声时间轴。
2. 打开「小岛书店」→ 查看 Pi 失败说明 → 重试纪要 → 到队列连续「推进一步」直至完成 → 返回会议阅读。
3. 在已完成会议点「重新转写」或「重新纪要」→ 阅读输入与影响说明 → 旧结果仍可读 → 在队列模拟失败、重试/取消 → 成功后阅读历史版本。
4. 修改设置，输入不合法分段时长并保存 → 纠错 → 跨组修改 → 离开时取消 → 保存；或放弃草稿。
5. 模拟录制并停止封存，或导入样例 → 查看排队 → 处理完成；批量导出/删除；恢复演示数据。

### 日期、样例时间与只读行动项

- 首次打开和「恢复演示数据」默认 **最近7天**，从本机今天前6天到今天，含两端。最近3天是今天及前2天；本周从本地周一到今天。日期使用本机自然日，不将本地时刻转换成 UTC 日期。
- 快捷按钮选中时会同步显示起止日期；手动改日期后显示「自定义日期」，不再保留快捷选中。可以设置任意更早日期，非永久7天限制。「清除筛选」清空所有条件并显示**全部日期**；页面内往返保留当前筛选；刷新/重新打开恢复默认最近7天。
- 六场样例以**首次生成或重置当天**为锚点，分布在当天及前5天；首次生成即尝试保存锚点。页面注明样例生成日。再次打开不会把已有会议每天改成新会议；超过7天后可手动查找，或恢复演示重新生成。模拟新建会议使用当日本地日期。行动项日期为虚构纪要原文示例，不产生到期提醒。
- 沿用本地存储键 `omm-webui-fictional-v1`；数据结构升级为第2版。第1版虚构库首次加载按旧样例基准日 `2026-10-17` 的日差整体平移到迁移当天；保留标题、正文、配置和操作结果，清除当前及历史行动项完成标记。迁移后保存，不再每日平移。损坏或无法写入时明确提示并降级；「恢复演示数据」始终可重建样例。
- 行动项保留原文、负责人和日期，**仅供阅读**。没有勾选、完成状态、跟进或外部任务同步；Markdown 导出也使用普通条目。

### 重新处理的演示规则

- **重新转写**：输入为已封存音频，使用当前转写配置；本演示完成后衔接纪要。确认前说明对两类结果的影响。
- **重新纪要**：输入为完整已提交逐字稿，不重跑音频识别；使用当前 Pi 配置创建新尝试。
- **重试失败阶段**：沿用该次尝试和检查点，保留原配置快照；与创建新尝试的「重新纪要」不同。
- 旧结果始终可读。新结果成功提交后才切换当前阅读版本；失败/取消不抹去旧版。历史阅读只读。
- 演示采用固定步数推进，不模拟真实执行耗时、资源调度或重试退避。取消只是停止模拟状态。

### 配置映射与边界

- 录音/检测：`audio.opus_bitrate_kbps`、`segment_ms`、`start_delay_ms`、`end_grace_ms`、`poll_ms`、`capture_executable`、`lark_executable`、`rtc_log_dirs`。
- 本地转写：`worker_executable`、`asr.threads`、`asr.timeout_ms`、`asr.library_path / encoder_path / decoder_path / tokens_path / vad_path`。固定模型版本只读说明；请求线程数不是硬性 CPU 上限。
- Pi 纪要：`pi.provider / model / executable / node_executable / prompt_version / timeout_ms / max_input_bytes / max_output_bytes`。模型与提供方为虚构名称，路径统一使用 `/demo/`。
- 通知：`notifications.enabled / show_meeting_title / events`，六种生命周期/失败事件；不含正文、凭据。
- `version`、固定模型版本、自动录音/同意持久策略以及 XDG 根不伪装成普通可编辑配置：自动录音独立确认并立即保存演示状态；存储目录只读说明。浏览器状态是扁平演示模型，**不是可用于 OMM 的 config.json**。
- 新处理尝试使用新配置；旧任务保留原快照，码率影响后续入队片段。网页保存如何让服务加载、生效到哪次录音及冲突处理，均须真实开发前再确认。
- 前端只校验可表达的输入形状；绝不检查本机文件、模型哈希或认证有效性。真实配置验证仍由现有核心负责。
- API 密钥、令牌、密码不进入表单或本地存储。使用 Pi 支持的方式配置专用认证；真实转写后直接生成纪要，不新增文字外发审批开关。

## 模拟与安全边界

- 全部会议、人物、处理结果和目录都是虚构。新导入/录制结果复用纸舟样例展示结构，时间标记按样例时长缩放，不是任何真实识别结果。
- 不读取个人会议、用户配置、凭据或安装元数据；无真实文件选择器、无后端、无 WebSocket、无远程 API、无外部字体/图片/CDN、无外部网络请求。
- 不调用 `omm`、录音硬件、Pi、语音识别或系统权限；不播放音频、不用 TTS、不自动播放、不发送桌面通知。
- 页面内容安全策略禁止连接和媒体加载；模板数据转义、插入前限制标签和属性，输入的 HTML 只作为普通文字显示。
- 本地存储键：`omm-webui-fictional-v1` 只存虚构演示数据及界面参数，`omm-webui-theme-v1` 只存外观选择。损坏状态分别回退初始样例/系统外观，存储被拒绝时仍可操作。凭据不入本地存储。
- 原生对话框负责焦点约束、Escape 关闭；危险确认先落在取消控件；关闭返回原控件；资料页签支持左右箭头、Home/End；表单有标签、错误关联与焦点定位。浏览器原生离开提示取决于交互和浏览器策略。
- 未开发：云协作、多用户、远程访问、分享、日历、实时字幕、说话人识别、真实服务控制。用户已批准 Tauri 2 桌面方向，见[技术提案](technical-proposal.md)；正式工程、原生命令权限和媒体通路仍待新版 Demo 确认后设计实施，Axum 通用浏览器入口后置。
